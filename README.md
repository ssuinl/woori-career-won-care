# 커리어WON케어 — 이직·퇴직 금융 정리 AI 에이전트

우리은행 X SSAFY 우리WON뱅킹 아이디어 경진대회 · 3인 팀 · **본선 장려상** (2026.11.19)

## 목적
이직하는 사람은 퇴직연금(IRP), 급여계좌, 자동이체를 직접 하나씩 정리해야 합니다. 그 과정에서 퇴직금이 다른 금융사로 빠져나가는 일이 많습니다. 커리어WON케어는 **퇴사 전부터** 이 정리를 먼저 도와주는 우리WON뱅킹 안의 AI 에이전트입니다.

- **핵심 타깃:** 퇴직금을 받는 만 55세 미만 고객 (IRP 의무 이전 대상)
  - 연령대가 아니라 규제 기준으로 정의해서, 50대 초반도 자연스럽게 포함됩니다.
- **차별점:** 퇴사 "후"가 아니라 "전"에 개입합니다.
  - 은행과 우리투자증권이 한 앱에 있다는 우리금융만의 장점으로, 고객 자산을 그룹 안에 붙잡아 둡니다.

## 데이터 (근거 자료)
발표 자료에 넣은 공개 수치입니다. 원 출처는 발표 자료에 표기했습니다.

| 지표 | 값 |
|---|---|
| 퇴직연금 적립금 | 554조 원 (2026.6) |
| 우리은행 퇴직연금 점유율 | 6.1% (34.0조 원) |
| 연간 퇴직연금 이전 규모 | 약 13.8조 원 (2026 상반기 6.9조 원 기준 연환산) |
| 연간 이직자 | 385만 명 (2024, 국가데이터처 일자리이동통계) |
| 벤치마크 | 한국투자증권, 연금 이전 차별화로 8개월간 570억 원 유입 |

## 방법
1. **전수조사:** 우리WON뱅킹의 앱 기능, 금융 전략, 경쟁사(KB·신한·토스·카카오뱅크), 고객 불만, 규제 환경을 조사했습니다.
2. **아이디어 3종 비교:** 이직 매니저 / 소상공인 현금흐름 예측 / 뱅크 에이전트 API
   - 2026년 6월 우리은행 SSAFY 대회의 수상작과 겹치는 '보호' 주제는 피하고, '수익·성장' 주제로 방향을 바꿨습니다.
   - 소상공인 안은 핵심 기능이 다른 앱(우리WON기업)에 있다는 실현성 문제가 있어서 제외했습니다.
3. **서비스 설계:** 퇴사 예정 감지 → 퇴직연금·급여계좌·자동이체 정리 체크리스트 → 그룹 내 IRP·증권 연계 흐름, 휴대폰 UI 시안
4. **수익 추정:** 가정치를 실제 공시 수치로 바꿔서, 점유율 +1%p 목표(연 138억 원)가 벤치마크의 약 1/6 속도라는 점을 보였습니다.
5. **로드맵:** Phase 1 핵심 타깃 → Phase 3 은퇴 연령 고객으로 확장
